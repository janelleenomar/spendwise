### Project Description
A fully functional Flutter application designed to track personal daily expenses using local data persistence. This repository demonstrates the implementation of the `Hive` NoSQL database for offline storage, including custom data models with TypeAdapters, reactive UI updates using `ValueListenableBuilder`, and complete CRUD (Create, Read, Update, Delete) operations. The project also features a monthly budget tracker with visual progress indicators and a local `.txt` file data export functionality as part of the laboratory submission requirements.
